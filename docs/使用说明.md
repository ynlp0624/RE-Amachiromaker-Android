## 一、怎么装

1. 把 **`RE-Amachiromaker-v1.0.0-android.apk`**（39 MB）传到手机上
   —— 数据线、微信「文件传输助手」、网盘都行。
2. 在手机上点这个文件安装。
3. 系统会弹一句「**是否允许安装未知应用**」→ 点**允许**。
   （因为这个包是雫自己签名的，不是从应用商店下的，安卓会多问一句，正常喵。）
4. 装好后桌面图标叫 **RE:Amachiromaker**，点开就能用。
   **第一次打开会弹「使用须知」**——那是原作者的版权要求，点「同意」就好。

> 想装到电脑上的安卓模拟器里也行：把 APK 直接**拖进模拟器窗口**即可。

## 二、怎么捏

界面分三块，从上往下看：

| 位置 | 是什么 | 怎么用 |
|---|---|---|
| 最上面一横条 | 标题栏 | 右边三个按钮：**日间/夜间**（换浅色深色）、**关于**（版权与作者信息）、**须知**（使用须知） |
| 中间大图 | **预览区** | 所有贴图一层层叠出来的成品，改哪里它立刻变 |
| 下面网格 | **贴图选择区** | 先点上面一排「部位标签」选部位，再在网格里点想要的贴图 |

**部位标签**（就是那排带小图标的方块）从左到右是：
背景 / 后发 / 脸 / 腮红 / 右眼 / 左眼 / 右眼高光 / 左眼高光 / 嘴 / 眉毛 / 表情 / 痣 / 兽耳 / 角 / 耳钉 / 追加发 / 衣服 / 项圈 / 刘海 / 侧发 / 发饰 / 发饰2 / 其他 / 袖子 / 贴纸。
（标签可以左右滑，一共 25 个部位）

**小技巧喵：**
- 网格最左边那个**虚线叉叉**＝「这个部位不要」（比如不想要猫耳就点它）。
- 有些部位点完贴图后，**下面会冒出一排彩色圆点**（比如头发）——那是同一款贴图的不同颜色，点圆点就换色。
- 带蓝框的就是**当前选中**的那个。

## 三、五个按钮

| 按钮 | 干什么 |
|---|---|
| **重置** | 回到官方默认的那张脸（白发猫娘） |
| **保存 PNG** | 存一张 600×600 的成品图，位置在手机相册的 **`Pictures/Amachiromaker/`** 里，相册 App 直接能看到 |
| **保存 PSD** | 存一个**分层**的 `.psd` 文件（能用 Photoshop / Krita / GIMP / Photopea 打开，头发、眼睛、衣服都是分开的图层，可以继续改） |
| **载入预设** | 选一个 `.json` 搭配文件，一键换装 |
| **导出预设** | 把现在这套搭配存成 `.json`，发给别人别人也能用 |

> 保存 PSD 和预设时会弹系统的「保存到哪」窗口，挑个位置点「保存」就行。

**雫给自己捏的那张**已经放在 `shizuku-preset.json` 里啦～
想复现的话：点「载入预设」→ 选这个文件 → 就是下面这张：

![雫](shizuku-nekoha.png)

`shizuku-nekoha.png` 是成品图，`shizuku-nekoha.psd` 是分层源文件（16 个图层）。

## 四、它为什么不是「网页套壳」

老婆之前说的是对的：**没套壳**。它不是拿浏览器装个网页进去，是真的用安卓自己的零件重做的：

| 网页版 | 这个 App |
|---|---|
| React + HTML + CSS 界面 | **Kotlin + Jetpack Compose** 原生界面（安卓自己的控件） |
| 浏览器 `<canvas>` 叠图 | `android.graphics.Canvas` 把贴图直接画到 `Bitmap` 上 |
| ag-psd 库在浏览器里生成 PSD | 纯 Kotlin **手写的 PSD 写出器**（每层一个 RGBA 图层 + 图层名 + 位置） |
| 图片从 CDN 下载 | 1111 张贴图**全部打包进 APK**（`assets/` 里），离线也能用 |
| localStorage 存进度 | 安卓 SharedPreferences |
| 需要联网 | **连联网权限都没申请**（安装包里没有 INTERNET 权限） |

装包里的结构是这样的：`assets/image_maker/…` 是素材、`classes.dex` 是编译后的原生代码，
**里面没有 index.html、没有 .js、没有 .css**，也没有 WebView。
（想看证据的话可以解压 APK 数一数喵~）

工程源码在 `E:\neko\AmachiromakerApp\`，用 Gradle 就能重新打包，
细节见同目录的 `README-ANDROID.md`。
